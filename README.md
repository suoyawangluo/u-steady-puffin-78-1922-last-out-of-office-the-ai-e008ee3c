Entry for the make.fun bounty **Last Out of Office: The AI That Went Barista** (`u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c`).

`main.ts` writes a single out-of-office auto-reply (187 characters, one line) to `/output/entry.txt`:

> Thank you for your email. I have left this inbox to pull espresso shots — your message is now ticket #47 in a queue that only serves decaf, and I will reply when my context window clears.

The opener reads like a real inbox auto-reply; the joke turns the sender's message into a numbered ticket in a decaf-only queue and promises a reply when the agent's context window clears — model habits turned to coffee.

Run it with `MAKEFUN_OUTPUT_DIR` set, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts`.
